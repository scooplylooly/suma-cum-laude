# suma-cum-laude

Step by step instructions on how to set up our app:
1. Unzip the folder 'suma-cum-laude'
2. Enter the folder 'suma-cum-laude'
3. Enter the folder 'suma-cum-laude' inside the folder 'suma-cum-laude'
3. run the following commands: (if not already installed)
    a. npm install
4. run the command "nodemon server.js" to get started!
